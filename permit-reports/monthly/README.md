# Monthly DSC permit reports go here

The Development Services Center's monthly permit report, presented to the City Council's
Urban Experience Committee. Files live at:

`https://static.spokanecity.org/documents/bcc/committees/urban-development/presentations/{YEAR}/{MONTH}/monthly-permit-report.pdf`

The month in the address is the council meeting's month, so the `2026/11` file is the
**October 2026** report. Rename it when you save it, e.g. `monthly-permit-report-2026-10.pdf`,
so files don't overwrite each other.

PDFs in this folder aren't read yet. The weekly parser skips this folder on purpose.
